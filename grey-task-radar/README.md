# GREY Task Radar
Phone-first installable web app for discovering public task listings and checking basic URL risk signals.

## Android
Open index.html in a browser or serve this directory on a static host. For install behavior, use HTTPS hosting and the browser's Add to Home screen option.

## Limitations
Search opens search-engine queries; it does not scrape or verify live listings. The URL analyzer checks URL structure only, not page content, employer legitimacy or payout. No fake job results are displayed. It does not crawl Tor/onion services, private pages or illegal marketplaces. Bookmarks stay in local browser storage. No login, payments or paid API required.
