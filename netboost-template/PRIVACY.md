# Privacy
NetBoost keeps test history in local device storage by default. It does not collect passwords, inspect private communications, or perform unauthorized network scanning.

Network measurements necessarily make requests to the configured measurement endpoints. Those endpoints may receive normal HTTP metadata such as IP address and request timing. Users should review endpoint policies before enabling third-party/custom endpoints.

Wi-Fi SSID and detailed radio information are not fabricated when Android or the WebView does not expose them.
